# Desenvolvimento Web

Disciplina do 4º semestre (2026.2), turma UN 0726.

## Entregas

| Pasta | Projeto | Descrição |
|---|---|---|
| [`Aula01/`](Aula01) | William Arena | Site de games, eSports e hardware com arcade jogável no navegador (Snake, Breakout e Jogo da Memória) |
| [`Aula02/`](Aula02) | Escola Virtual | Formulário de Pré-Matrícula montado **somente com HTML**, sem folha de estilo |

Todos os projetos usam HTML, CSS e JavaScript puros — sem frameworks, sem
dependências externas e sem etapa de build. Abrir o `index.html` da pasta no
navegador é suficiente para rodar.

A `Aula02` é a exceção proposital: o enunciado pede o formulário **apenas com
HTML**, então o alinhamento é feito com elementos e atributos da própria
linguagem (`table`, `fieldset`, `align`, `size`, `center`), sem CSS.
